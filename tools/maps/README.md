# ASCII-формат карт

`tools/build_maps.gd` перетворює кожен `*.txt` тут на `maps/<ім'я>.tres` (`MapAscii.parse`).

```
# коментар (поза сітками — будь-де після '#')
name_key=map_x          # ключ перекладу назви
ground=DRY              # DRY | MUD | FROZEN
tiles:
<H рядків по W символів>
surface:                # необов'язково
<H рядків по W символів>
spawns:
<type_id> <x> <y> <facing>   # лише гравець 0; гравець 1 — дзеркало через центр
```

## `tiles:` — вид тайла

| символ | вид |
| --- | --- |
| `=` | ROAD |
| `.` | FIELD |
| `T` | FOREST |
| `^` | HILL |
| `~` | MARSH |
| `w` | WATER |
| `B` | BUILDING |
| `r` | RUBBLE |
| `H` | BRIDGE |
| `x` | BRIDGE_DESTROYED |

## `surface:` — косметичний підтип

**Лише вигляд.** Жодне правило його не читає, і в `Board` він не потрапляє. Сітка має
ту саму форму, що й `tiles:`. Цифра на клітинку, `.` — те саме, що `0`, тобто типовий
вигляд виду. Без цієї секції підтип усюди `0`. Значення — `MapData.RoadSurface`,
`FieldSurface`, `ForestSurface`; для інших видів пишіть `.`.

| вид | `0` / `.` | `1` | `2` |
| --- | --- | --- | --- |
| ROAD | асфальт | ґрунтовка | бруківка |
| FIELD | луг | рілля | — |
| FOREST | мішаний | сосновий | листяний |

## `outer:` і `outer_surface:` — зовнішнє кільце

**Лише пейзаж за краєм дошки**, щоб за найбільшого віддалення
не було видно краю світу. Жодне правило, `Board` чи `Rules` його не читає, юніт туди не
ступає. Ширина кільця — заголовок `outer_margin=<m>` (поставні карти — 12); без нього `0`,
кільця немає. Відступ і секція `outer:` мають бути разом.

`outer:` — сітка `(W+2m)×(H+2m)` тією ж легендою, що й `tiles:`. Дошку в ній не повторюють:
її місце — суцільний блок `#` рівно `W×H`, а `#` поза ним — помилка. `outer_surface:`
(необов'язкова) — та сама форма й той самий блок `#`, решта — за правилами `surface:`.
Рядок сітки, що починається з `#`, — коментар; рядок кільця з `#` не починається ніколи.

Річка не обривається на краю дошки — тече крізь кільце до його зовнішнього краю; дорога,
що доходить до краю, веде далі — до хутора, перехрестя чи за край кільця. Кільце
продовжує дошку: на симетричній карті воно теж симетричне. Огляд: `python3 tools/map_png.py <тека>` малює кожну
карту з кільцем у PNG, дошка обведена червоним.

Як розмічено поставні карти: асфальт — головна дорога від бази до бази, бруківка — вулиці
містечка, решта доріг — ґрунтовка. Поля й ліси розмічені цілими ділянками, а не шумом
по клітинках.
